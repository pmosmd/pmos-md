MCP for PMs 10 · servers

official servers by workflow stage · reviewed Oct 2026

MCP lets your AI agent reach into the tools you already use. Only vendor-official servers are listed, in the order a PM meets them, not all 300+.

tool server status what PMs use it for
Dovetail discover dovetail-mcp github.com official Connect your agent to the Dovetail API so research can feed discovery docs and specs. Runs locally with your API token.
Notion define Notion MCP developers.notion.com official Read and write docs, databases, and wikis. Summarize meeting notes, update specs.
Jira + Confluence plan Atlassian Rovo MCP server atlassian.com official Search and summarize Jira and Confluence, create and update issues and pages. Cloud only.
Linear plan Linear remote MCP linear.app official Manage issues, projects, and cycles. Pull sprint context into PRD drafts.
Productboard roadmap Productboard MCP Server productboard.com official Pull current specs into a coding agent, post questions back, and update status.
Figma design Figma MCP server help.figma.com official Give agents the real components, variables, and layout from your Figma files. The remote server is on all seats and plans.
GitHub build github-mcp-server github.com official Review PRs, search issues, understand codebase context without asking engineering.
PostHog measure PostHog MCP posthog.com official Ask product-analytics questions in plain text and let the agent query PostHog. The hosted endpoint is free to connect.
Amplitude measure Amplitude MCP Server amplitude.com official Query and create charts, dashboards, experiments, and cohorts in plain language. For existing Amplitude customers.
Slack communicate Slack MCP server docs.slack.dev official Search channels and read threads for past decisions, and catch up on a project. Workspace admins approve each client.
